# Bartmoss

2026–2027赛季VEX V5机器人控制程序，面向八电机差速底盘、双电机机械臂、夹爪和气动机构，支持手动驾驶、自动路线、分项测试与遥测。

**当前版本：`2.1.0-beta.1`（预发布）。** 本版用于继续调路线与实车验收，上一发布基线为 `2.0.6-route3`（[92eba1f](https://github.com/HudEn5/Override/commit/92eba1f0ec2c7923323be5330e8f5db8ef05f707)），历史标签 `core-v2.0.0`保留。

本版提供编码器＋IMU位姿推算、MoveToPoint、单侧Swing、相邻多弯不停顿衔接。所有路线动作必须显式填写末尾 `timeout_ms`；超时停车并终止路线，组合内部阶段共用预算，多弯逐条计时。接口和单位见[路线指南](docs/ROUTE_GUIDE.md)。

当前配置：菜单A自动、B手动、X测试；手控底盘满杆6V，自动目标上限540电机rpm（450轮端rpm）。自动选中路线7：`MoveToPoint(300,300,400,300,10000)`，用于修正复测。程序不会因下载而自动开始路线，用户仍需按菜单规则启动。

本分支 `抬升机构封装` 是基于 GitHub `d902245` 的机构调试快照，程序版本仍为 `2.1.0-beta.1`。抬升上电自动记录首次有效编码器读数为相对零点，无需点屏幕；B进入手动并松键回中后，Y单次执行当前用户目标 `LiftTo(240, 3000)`。`240` 为平均电机角度°，还未标定为毫米；软件允许范围为0～600°，修改上限不会自动改变目标。PID为P100/I20/D8，积分上限2000mV，起步助推12V、最多100ms。A启动原底盘自动时并行触发一次相同抬升调用；当前 [route.cpp](src/route.cpp) 仍没有可编排的Lift步骤接口。集中调参入口和按键端口表见[机构调试定位表](docs/DEBUG_MAP.md)；下载后核对首行 `LIFTPID`。

本快照供继续调试，尚无实车证据可以排除抬升尾段抖动或确认 `Memory Permission Error` 根因已解决，不作为抬升验收完成。原底盘实车基线与限制继续保留，见下文及[实验日志](LAB_NOTES.md)。

验证范围：多弯路线已有一轮DONE；新Swing左右各一轮DONE，均1273ms，停后误差约0.51°/0.30°，重复性待验。MoveToPoint原版本曾在目标(300,300)产生8.28mm推算偏差，本版加入直行前有界重新对准，模型通过，尚待实车复测。5mm判据不等于已证明的地面定位精度；无独立里程计时横向侧滑不可观测。宿主机回归曾出现间歇断言，单项复查通过但根因仍待查。具体记录见[实验日志](LAB_NOTES.md)。

## 功能

- **手动控制**：前后/转向混控、双臂直接电压控制、夹爪及气动控制。
- **自动抬升**：上电建立相对零点，独立约10ms线程按平均电机角度运行PID，无重力补偿；毫米接口等待三点实测标定。
- **距离直行**：梯形速度规划、编码器位置反馈、惯导航向保持、前馈与速度 PID。
- **原地转向**：相对转角或绝对朝向控制，支持速度变化限制和停稳判定。
- **连续圆角**：直行、转弯、直行连续衔接，根据曲率变化及左右轮加减速约束提前限速。
- **定时前推定位**：`PushFor(1000, 4.0, 3000)`以4V前推一秒，用于对接物理定位机构，到时制动并停稳。
- **独立运行环境**：日常测试、比赛、标定分别构建，共用底层运动控制器。
- **遥测与并发保护**：通过 VEX VS Code WebSocket 接收数据；共享快照和采样队列使用 mutex。底盘、夹爪、气动由主循环输出，抬升手动/自动由同一个独立线程输出。

### 开发环境

| 项目 | 要求 |

| 主控与手柄 | VEX V5 Brain、V5 Controller |
| 固件开发 | Visual Studio Code、VEX Robotics 扩展及其 C++ 工具链 |
| VEX SDK | `V5_20240802_15_00_00` |
| 构建脚本 | Windows PowerShell |
| 数据接收 | Node.js 22 或更高版本，仅采集时需要 |
| 离线测试 | Linux / WSL、支持 C++11 的 g++ |

SDK 和工具链由开发环境提供，不包含在仓库中。

### 获取与构建

```powershell
git clone --branch '抬升机构封装' https://github.com/HudEn5/Override.git
cd Override
.\scripts\build.ps1 -Rebuild
```

使用 VS Code 打开仓库根目录，确认 VEX 扩展已识别工程、SDK 和工具链。
脚本支持 `-SdkPath`、`-ToolchainPath` 指定安装位置；多电脑配置见 [设备与同步说明](DEVICE_SYNC.md)。

默认输出为 `build/Bartmoss.bin`，程序名 **Bartmoss**，下载槽位 **1**。
通过VEX扩展下载后核对版本 `2.1.0-beta.1` 及本轮机构标记 `LIFTPID`，保持静止等待惯导校准完成，再从A/B/X菜单选择模式。抬升以首次有效编码器读数对应的开机姿态为零点，不会自动寻找机械最低点。

### 运行一次底盘测试

1. 在未接场控或比赛开关时运行程序，等待惯导校准和车辆停稳。
2. 在菜单按 X 进入测试，松开选择键；使用上/下选择项目、右/左选择方向。
3. 按一下 A 启动动作，松开后程序继续执行到 `DONE` 或故障停止。
4. 按 B 可取消；拨动摇杆可取消并立即接回手动驾驶。

普通测试配置默认STR；当前高速配置默认CNR 90°。菜单按A直接执行整条自动路线，B进入手动。
手动/测试停车后长按B一秒返回菜单；接入场控后由场控接管。完整说明见 [启动模式](docs/STARTUP_MODES.md)。

### 日常测试环境（TEST）

| 输入 | 动作 |
| --- | --- |
| 上 / 下短按 | 停稳时循环选择 STR 直行、TURN 原地转向、CNR 连续圆角 |
| 右 / 左短按 | 选择正 / 负方向：直行前进/后退，转向与圆角逆时针/顺时针 |
| A | 启动选中的测试 |

```cpp
using namespace route;
RunRoute({
    DriveStraight(1500, 540, 6000),
    Turn(90, 540, 3000),
    DriveStraight(1500, 540, 6000),
});
```

发布基线默认直行330rpm、原地转向140rpm；当前高速默认540/540电机rpm。距离mm、角度度、等待毫秒；`Turn`为相对角，正角逆时针。

测试与比赛共用高速参数，低速三项测试保留；任一动作故障或取消会停止整条路线。
`Wait` 不阻塞主循环。完整接口、按钮和验证范围见 [路线指南](docs/ROUTE_GUIDE.md)。

## 遥测与标定

### 采集数据

遥控器通过 USB 连接电脑，并与主控保持无线连接；VS Code 的 VEX 扩展开启本机 WebSocket 服务。
仓库工作区设置使用 `127.0.0.1:7071`。接收脚本只读取数据，不发送运动指令。

```powershell

```

### 专用标定环境

## 位姿推算（开发分支）

使用八台驱动电机编码器的左右平均位移和4号口IMU连续转角，按差速模型逐帧推算底盘中心位置。曲线采用中心弧长和半角修正；不积分滤波转速，也不增加线程。

- 坐标：X为启动时前方，Y为启动时左方，单位mm；朝向逆时针为正，单位度，可超过360°。
- 启动保持车静止，等IMU校准完成。首组完整反馈建立编码器基准，对应 `(0,0,0)`，不用手动清零电机。
- 主控显示X/Y/H与 `WAIT`、`OK`、`RESET`；遥控器保持原动作显示。本轮非Calibration本地LOG自动开启，接收脚本额外保存 `-pose.csv`，高速模式仍为2Hz。
- `drive::odometry::SetPose(x,y,heading)` 用于指定已知场地坐标，只允许在主循环调用。正常重设保留传感器基准；失效后下一组完整反馈重新建立基准。该API不写硬件，也不改变原动作的IMU坐标。
- 运行中反馈丢失、明显跳变、时间倒退或更新间隔超过200ms时锁存 `RESET`，保留最后可信坐标和时间，不能自动恢复成有效。须回到已知位置重新设置位姿，或重新启动并建立新的局部原点。

首轮验证：先静止观察坐标，再手动直行、后退、原地转向；最后测量一条已知距离与转角路线，比较实际终点和X/Y/H。原地转向中心位置应基本不变，前进/后退坐标方向应相反。位姿失效不阻断原距离/转向动作，但会终止依赖坐标的MoveToPoint。

电机编码器会受轮胎打滑、轮径误差和碰撞影响；IMU只约束航向，不能消除位置漂移或识别车被搬动。物理定位后仍需提供已知坐标，`PushFor` 不自动归零。`MoveToPoint` 已接入，按[路线指南](docs/ROUTE_GUIDE.md)先验证定位与短距离点位，再调路线。

## 项目结构

```text
include/    硬件配置、控制算法、状态与接口；本轮增加机构封装及辅助头文件
src/        主循环、硬件适配、路线、显示与回传
scripts/    构建、数据接收、软件测试与 Git 同步工具
tests/      宿主机测试及硬件替身
docs/       代码结构说明
vex/        VEX 构建规则
.vscode/    工程、工具链补全与任务配置
```

构建产物、采集数据和本地备份保存在被 Git 忽略的 `build/` 中；SDK 与本机配置不随仓库分发。

- `build/Bartmoss.bin` 为VS Code默认下载文件；test/competition/calibration/highspeed为各模式产物，位置保持原样。
- `build/logs` 集中构建、宿主机检查日志及整理清单；build.ps1与test-host.sh自动写入带时间戳的日志。
- `build/data` 保留原始遥测和分析；`build/backups` 保留原快照；`build/archive` 归档旧检查、候选副本、历史分析和视频参考。
- `docs/history` 保存阶段实验与旧整定说明；日常从LAB_NOTES入口查看当前状态，不把历史参数当成现用参数。

当前操作文档包括代码结构、路线指南、启动模式、高速整定、转向整定及本轮机构调试定位表；笔记本交接提示已合入DEVICE_SYNC。
