# Bartmoss v1.0.0 · 2026–2027 手动控制

本仓库发布首版手动控制程序及其构建、测试和监测工具。

独立的 VEX V5 C++ 工程，面向左右各 4 电机的传统差速底盘。
参考 [Tungsten](https://github.com/Dove-ctrl/Tungsten) 的手控思路，保留相近的设备和变量命名；
不依赖 ElementOS、自动路线、全向混控、里程计或 WebSocket；手臂使用独立角度 PID。

## 手柄操控

| 输入 | 动作 |
| --- | --- |
| 左摇杆上下 Axis3 | 前进 / 后退 |
| 右摇杆左右 Axis1 | 左转 / 右转 |
| 按住 R1 / R2 | 增大 / 减小手臂目标角度，松开保持目标 |
| 按住 L1 / L2 | 夹爪夹紧 / 松开 |
| X 按下沿 | 切换 H 口气动状态 |

左侧底盘输出为“前后 + 转向”，右侧为“前后 − 转向”。只操作右摇杆可原地转向；
同时操作两个摇杆可边走边转。混合输出超出电压上限时，两侧同比例缩小。
摇杆死区为 5%，死区外线性映射；底盘最大输出 ±12000 mV，循环周期 20 ms。

两侧手臂接收同一平滑目标，由两个持续运行的角度 PID 分别跟踪各自编码器并输出电压；
不再重复调用 `spinToPosition`。ArmR 使用已提供的反转配置。
任一侧电机掉线，或两侧编码器位置差超过 `ARM_MAX_DIFF` 时，手臂自动停止；
恢复后从当前实测位置重新跟随，不会追赶掉线前的旧目标。
每次启动程序前，必须把手臂放在起始位置；程序将两台手臂电机的编码器设为 0°。
没有归零传感器，程序不会自动寻找起点。目标使用电机编码器角度，并非手臂关节角度。
目前已取消 90° 上限，R1 可继续增加目标；仍保留 0° 下限。
按住 R1/R2 时目标以 60°/s 增减，松开后继续到达该目标并保持；同时按下两个按钮时目标不变。
目标角最多领先实测角 10°：手臂被卡住时目标不会继续跑远。按住期间若约 1 s 内未按指令方向
累计移动 0.05°，判定为堵转，目标固定为触发时的实测位置；松开再按或换向后才能继续。
慢速运动的位移跨周期累计，反向移动不记为有效进展，锁存目标不会继续跟随实测位置漂移。
目标角度软件限幅不能代替机械限位，也不能保证实际位置绝不超出范围。
目标在进入 PID 前经过一阶低通滤波与目标速度限幅；输出电压另有变化率限制，缓和启停和换向。
PID 对测量值求微分并做低通滤波，积分项有积分区间、限幅和条件积分，降低噪声和饱和积累。
使能期间由自定义 PID 持续保持目标；禁用或手臂异常时退出电压控制，并按配置的 `hold` 停止。
不使用内置位置动作超时。手臂带有目标领先限制、累计方向位移堵转检测、在线和位置差检查。
手臂 PID、下坠问题及提速效果尚待完整实机验证；软件测试通过不代表已完成整机验收。
夹爪松开按键后使用 `hold`，底盘使用 `coast`；夹爪两个相反按键同时按下时停止。
手臂、夹爪和底盘可以同时操控。
X 按住不会反复切换；启动、重新启用或手柄重连时已经按住 X，需要先松开再按下。

## 本赛季硬件

端口、齿轮比和反转方向与提供的设备配置一致，集中在 `include/control-config.h`：

| 设备 | 端口 | 齿轮比 | 反转 |
| --- | --- | --- | --- |
| LF | 12 | 6:1 | true |
| LM | 1 | 6:1 | false |
| LBD | 11 | 6:1 | true |
| LBU | 13 | 6:1 | false |
| RF | 6 | 6:1 | false |
| RM | 5 | 6:1 | true |
| RBD | 9 | 6:1 | false |
| RBU | 10 | 6:1 | true |
| ArmL | 3 | 36:1 | false |
| ArmR | 2 | 36:1 | true |
| Claw（小电机） | 15 | 18:1 | true |
| TogglePiston | 主控三线口 H | — | — |

智能端口填写主控上的编号 1–21，不使用 `PORT1` 等从 0 开始的 SDK 常量。
各电机配置格式为 `{端口号, 内部齿轮比, 是否反转}`。
程序先检查端口范围和重复占用，再创建设备；配置无效时只显示错误，不输出动作。
`LEFT_DRIVE`、`RIGHT_DRIVE` 和 `STRUCTURE_MOTORS` 由具名配置汇总，供内部遍历。
`INERTIAL_PORT` 仍保留为 0，不创建惯性传感器；当前操控不依赖它。

## 可调参数

- `YAxis` / `AngularAxis`：前后和转向摇杆映射，默认 3 / 1。
- `JOYSTICK_DEADBAND` / `MAX_VOLTAGE` / `UPDATE_TIME`：底盘死区、电压上限和循环周期。
- `ARM_MIN_ANGLE`：目标编码器下限，默认 0°。
- `ARM_UPPER_LIMIT_ENABLED`：默认 false，取消目标角度上限。
  `ARM_MAX_ANGLE` 保留为备用上限 90°，仅在该开关设为 true 后生效。
- `ARM_TARGET_SPEED`：按住按钮时目标变化速度，默认 60°/s。
- `ARM_MAX_VELOCITY`：平滑目标的速度上限，默认按 10 rpm 换算为 60°/s，并非电机实测转速的硬限。
- `ARM_TARGET_FILTER_TIME`：目标滤波时间常数，默认 0.06 s；越大，目标变化越缓。
  此组参数以实际提速一倍为调试目标，同时放宽目标领先量；实际倍数须在同一负载和行程下测量。
- `ARM_PID`：初始 `kp=600`、`ki=40`、`kd=20`，分别以 mV/deg、mV/(deg*s)、mV/(deg/s) 为单位。
  电压上限 6000 mV，输出变化率上限 12000 mV/s；积分项上限 1500 mV，积分区间 5°，微分滤波时间常数 0.08 s。
  这些是未实车整定的初值。减小 kp 可降低位置误差引起的输出强度；kd 提供阻尼，但过大也可能放大噪声。
- `ARM_MAX_LEAD`：目标角最多领先实测角的度数，默认 10°；手臂被卡住时目标不再跑远，松手后也可能继续追赶这段目标。
- `ARM_STALL_UPDATES`：按住时未取得有效方向累计位移的控制周期数，默认 50（约 1 s）；超过后锁存触发位置为目标。
- `ARM_MAX_DIFF`：两侧手臂编码器允许的最大位置差，默认 10°；超过后手臂停止。
- `CLAW_VOLTAGE`：夹爪输出为 6000 mV（6 V）。手臂由自定义 PID 调节电压，默认限制在 ±6 V。
- `ARM_UP_DIRECTION` / `CLAW_CLOSE_DIRECTION`：按钮动作对应的方向，默认 1；实车动作相反时改为 -1。
  这些参数不改变已提供的电机反转配置。
- `ARM_BRAKE_MODE` / `CLAW_BRAKE_MODE`：均为 `vex::hold`。
- `PISTON_INITIAL_STATE`：气动启动电平，默认 false；false/true 对应的实际伸缩方向由气路决定。
- `ArmUp`、`ArmDown`、`ClawClose`、`ClawOpen`、`Toggle`：对应的按键映射。

首次上车先架空底盘，确认各侧电机方向，再低速检查手臂升降、夹爪开合及气动状态。
手臂尚无自动归零或机械行程检测，也没有两侧位置差的主动同步补偿；
位置差超过 `ARM_MAX_DIFF` 时直接停止手臂作为保护。夹爪仍采用按住运行、松开保持。

## 运行与编译

在 VS Code 中打开仓库根目录 `Override`，使用 VEX 扩展编译和下载。
程序名 Bartmoss，平台 V5、程序槽 1，固定 SDK `V5_20240802_15_00_00`。PowerShell 也可执行：

```powershell
.\scripts\build.ps1
```

脚本默认使用 VS Code VEX 扩展工具链；自定义位置可传入 `-SdkPath` 和 `-ToolchainPath`。
产物为 `build/Bartmoss.bin`，`build/` 已忽略。

未连接场控或比赛开关时，手柄连接且配置有效即可手动调试；连接场控后，仅在启用的手动时段接受操控。
自动时段、禁用或手柄断连时停止所有电机，气动保持最后状态；实际比赛禁用期间的电机行为由 VEX 系统接管。
本工程没有自动动作。编译通过不能替代实车验证。

主控屏幕当前显示 `Bartmoss v1.0.0`：`CFG` 表示配置有效，`PAD` 表示手柄连接，
`RUN` 表示程序允许手控；`A3/A1` 为摇杆输入，`L/R` 为左右侧指令电压，
`Tick` 应持续变化。`FLD/SW/EN/DRV/AUTO` 是场控、比赛开关、启用、手动和自动状态；
`Motors L/R` 为两侧检测到的电机数，各应为 4/4。
`Tgt` 是目标编码器角度，`AL/AR` 是按上升方向归一化后的两侧实际角度。
`R1/R2` 为两个手臂按钮的原始输入，`ARM` 为手臂位置控制使能，`dt` 为控制循环间隔（ms）；
主控底行 `S` 为实际送入 PID 的平滑目标，`VL/VR` 为左右 PID 指令电压（mV）。
电机在线状态和实际电流仍可在遥控器第三行查看。
禁用和断连时取消手臂位置运动；重新启用时以实测位置作为新目标，不追赶之前未完成的目标。
诊断不绕过禁用或断连保护。

遥控器屏幕也显示手臂诊断数据，由独立线程刷新：

- 第一行 `T / L / R`：目标角度 / 左电机实际角度 / 右电机实际角度，单位度。
- 第二行 `1 / 2 / E / C`：R1 按下 / R2 按下 / 手臂使能 / 配置有效，1 表示是。
  末位数字循环变化，表示诊断数据仍在更新。
- 第三行 `V1 M11 I0.0/0.0`：V1 表示首版手控；M 后两位分别表示左右手臂电机是否在线；
  I 后两个数分别是左右电流，单位 A。

每行限制在 19 个字符内并覆盖旧内容；屏幕通信不会在手控线程中等待。

为兼容现有监测脚本，标准输出仍使用 `BM5,` 作为数据格式标识，包含 R1/R2、使能、原始目标角度、
两侧实际角度、电机在线状态和电流。它与电脑的 USB 游戏手柄输入是不同的数据通道。
使用 USB 数据线直接连接 V5 主控到电脑，关闭占用主控用户串口的 VEX 用户终端后，可以只读监测：

```powershell
.\scripts\monitor-arm.ps1 -Port Auto -DurationSeconds 60
```

脚本自动识别 V5 主控的用户控制台接口（PID_0501、MI_02）；用户串口编号可能变化。
V5 遥控器的命令接口（PID_0503、MI_01）不用于直接读取该输出。
监测记录保存在已忽略的 `build/arm-monitor-*.csv`。

纯控制逻辑测试可在 Linux / WSL 中运行：

```sh
mkdir -p build
g++ -std=c++11 -Wall -Wextra -Werror -pedantic -I include tests/driver-control-test.cpp -o build/driver-control-test
./build/driver-control-test
g++ -std=c++11 -Wall -Wextra -Werror -pedantic -I include tests/arm-pid-test.cpp -o build/arm-pid-test
./build/arm-pid-test
```

测试覆盖全部 40,401 种整数摇杆组合、手臂目标增减/保持/限幅、夹爪正反转、同时按键、
禁用及重连目标处理、气动按下沿、慢速累计进展与堵转目标锁存，以及 60°/s 双向目标链。
另有 PID 输出/变化率限幅、微分无目标冲击、积分限幅及防饱和、重置和目标平滑测试。

## 文件分工

- `include/control-config.h`：设备配置、按键和可调参数。
- `include/driver-control-logic.h`：前后/转向混控、机构动作与气动状态。
- `include/arm-pid.h`：独立于硬件的手臂角度 PID 和目标滤波。
- `src/robot-config.cpp`：端口校验、设备创建、手柄读取和硬件输出。
- `src/main.cpp`：比赛/连接状态判断和统一控制循环。
- `vex/`、`makefile`、`.vscode/`：VEX 构建配置。

构建产物、串口日志、本地参考代码及备份不随程序提交。
