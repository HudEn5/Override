# 自动路线编排

路线入口只有 `src/route.cpp`。测试与比赛执行同一份动作表，不需要手写状态机或修改运动控制器。
本页默认速度表描述发布的2.0基线；当前turn3实验直行和原地转向默认上限均为540电机rpm（轮端450）。
原地转向在实验档采用独立角加减速度的梯形规划，详见[转向整定](TURN_TUNING.md)。
省略速度参数时随`performance-config.h`开关选择，显式参数始终按电机rpm解释，详见[提速实验](HIGH_SPEED_TUNING.md)。

## 编写路线

```cpp
#include "autonomous.h"

void autonomous_program::RunRoutine() {
  using namespace route;
  RunRoute({
      DriveStraight(1500),  // 前进1.5m，当前最高540电机rpm，到位停稳。
      Turn(90),             // 原地逆时针相对转90°，当前最高540电机rpm。
      DriveStraight(1500),  // 转向后继续前进1.5m，三段之间不加Wait。
  });
}
```

动作之间用逗号分隔。距离单位 mm、角度单位度、速度单位电机输出轴 rpm、时间单位毫秒。
正距离前进、负距离后退；正相对角逆时针、负角顺时针。`Turn` 的参数是相对角，
与 Tungsten 的绝对方向式 `Turn` 不同；绝对朝向请使用 `TurnToHeading`。

| 接口 | 行为 |
| --- | --- |
| `DriveStraight(距离, 最高rpm=330)` | 高速直行，包含航向保持，到位后停稳 |
| `Turn(相对角, 最高rpm=140)` | 原地相对转向，到角度并停稳 |
| `TurnToHeading(朝向, 最高rpm=140)` | 按最短方向转到惯导绝对朝向 |
| `DriveCorner(前直线mm, 相对角, 后直线mm, 最高rpm=330)` | 直行、圆角、直行连续执行，中途不停稳 |
| `Wait(毫秒)` | 停车等待，无需控制器参数 |
| `PushFor(毫秒, 电压V=4.0)` | 机械定位定时前推，到时撤电压并等停稳 |

连续过弯用 `DriveCorner(500, 90, 500)`；三个独立动作 `DriveStraight`、`Turn`、`DriveStraight`
会分别停稳。圆角直线长度以切点为界，另有曲线路径长度。
当前默认即上述1500/原地90°/1500路线，采用turn3减速与尾段参数和高速直行参数；整条新路线尚待实车。
route2已取得一轮整条实车DONE，总约7.39秒；末段编码器剩余3.92mm，但前后直行偏航与转向误差合计使最终朝向比初始+90度少约2.01度，仍需优化和复核物理精度。
自动专用`AutoStraightControl`/`AutoTurnControl`已将`AUTO_SETTLE_MS`设为0：到位且零速门槛满足时即完成，不再增加100/250ms驻停计时。
距离5mm、转角0.8°、两侧5rpm及转向角速度2.5°/s门槛保留；仍需满足停车条件，X单项与圆角使用原250ms。
末段直行到DONE也不再额外计时；自动完成后的本地3秒回手动倒计时是独立流程，保持原样。
菜单A启动整条路线；X仍是独立STR/TURN/CNR测试。在测试中停车长按B一秒返回菜单后，再按A进入自动。

动作表每周期重建为栈上常量列表，调度器只推进当前动作，无堆分配、新线程或阻塞睡眠。
`Wait` 会让出控制周期，因此按键取消、反馈采样、场控禁用和显示仍正常处理。
不要在 `RunRoutine` 中直接使用阻塞 `vex::wait`，也不要在动作之间直接写电机。
同一次运行保持动作列表顺序固定；改源码、重新编译下载后再启动下一次。

## 定时前推定位

```cpp
RunRoute({
    DriveStraight(450), // 用距离闭环驶到定位机构附近，按实际场地改距离。
    PushFor(1000),     // 默认4V同向前推1秒，让物理定位机构对接。
    Wait(200),         // 可选等待。
    DriveStraight(-200),
});
```

也可写 `PushFor(600, 3.0)` 指定0.6秒、3V。时间单位毫秒；单次允许0～5000ms，0跳过；
电压范围0.001～12V。默认路线没有启用前推，只在源码注释中给出示例，需放在实际定位点附近。

该动作采用固定同向电压，不使用位置/速度/航向PID，避免接触后继续追距离或抵抗机械导向。
轮速变成0不会提前结束前推；达到设定时间即撤电压并制动，确认轮速低于5rpm持续100ms后才执行下一步。
撤电压后超过1500ms仍未停稳则停止全路线。计时以控制周期判定，结束可能落在截止时间后的一个更新周期。
反馈无效、传感器/电机离线、取消和场控禁用均终止输出；计时过程中无阻塞等待。

`PushFor`完成表示定时供电与停稳结束，不代表传感器识别到成功卡入；当前没有对接检测，也不会自动重置坐标。
默认4V的对接力度、自由行驶距离和机械配合尚需实车确认。该动作与Tungsten三参数`PushFor`不是同一个接口：
参考工程按功率、场地方向和时间生成运动目标，本工程专门封装沿机器人当前前方的定时电压。
回传保留 `-push.csv` 的计时、左右指令电压、状态和轮速，以及`-route.csv`的步骤结果。

## 高速参数

`include/performance-config.h` 是高速参数的共同来源，测试和比赛使用同一份副本配置：

- 直行采用 H3 基线：330 rpm 默认上限、320/320 rpm/s 加减速，不采用候选 H4 的增强位置增益。
- 原地转向复用 `TurnControl()` 的增益、240 rpm/s 目标变化限制与停稳判定；默认目标上限140 rpm。
- 圆角沿用最新提速配置：330 rpm单侧上限、180 rpm弯内上限、130 rpm入弯偏好，预测及直线加减速预算320/320 rpm/s。
- 速度、距离、曲率、航向误差仍会让实际速度低于上限；原地转向140 rpm默认值及复杂组合路线尚需实车验证。

前馈、速度 PID、角度控制和低速测试配置保留。直行已有多轮高速数据，圆角已有一次高速实车 DONE；
封装不代表弯中约10°跟踪滞后已消除，也不代表所有组合路线均已验证。

## 每段速度与不同角度

可以在动作参数中覆盖默认上限，无需改PID：`DriveStraight(500,250)`、`Turn(120,100)`、
`DriveCorner(500,30,500,250)`。单位均为电机输出轴rpm，不是角度/秒。
圆角最后的参数限制单侧轮速，弯内中心速度还受180rpm的统一上限及预测约束；短距离也未必达到指定上限。

直行采用梯形位置/速度参考、限加减速、位置纠偏、速度PID与航向保持；2.0原地转向是角度PD、轮速PID、
目标转速变化限制与停稳判定。当前turn3实验增加角速度梯形参考、实际剩余角度制动限速及规划跟踪纠偏。
圆角每次按当前角度、半径、轮距和速度上限重新生成空间速度计划，前向限制加速、后向预留减速距离，
同时限制曲率变化引起的左右轮加减速。30°短弯曲率变化更快，预测会自动降低弯速，
且规划上限优先于130rpm的入弯偏好；运行时还根据航向/角速度跟随主动降速。

`HEADING ERR`是圆角的运行中航向偏差超过15°保护，终点另要求1.5°；原地Turn的终点容差为0.8°。
不能把不出现某个报错等同于满足精度，也不能保证任意速度、负载和场地都不触发保护。
当前高速圆角模型新增432组：30°/90°/120°、左右转、100/200/330/600rpm上限、轮距和负载/左右响应变化，全部完成。
这仍是模型证据，500mm前后直线、250mm参考半径和所设响应范围之外的路线不在该验证范围。
实车只有90°单次完整记录，弯中曾落后10.2°；30°与120°的当前高速实车表现尚未确认。

## 无场控调路线

1. 在 VS Code 编译、下载并运行，等待惯导校准，确认A自动、B手动、X测试菜单。
2. 可先按Y打开回传，再按A选择自动；松开选择键、摇杆回中后执行一次整条路线。
3. B取消或拨动摇杆接回手动。上/下/左/右不更改文件中的路线。
4. 完成停车等3秒后回手动，显示上轮DONE或故障原因；停车后长按B一秒返回菜单，再选A重新运行。
5. 接收脚本保留 `-route.csv` 的轮次、步骤、等待和结果，以及各动作的原有数据。

开机按住 A、取消后继续按住 A、校准未完成或车辆未停稳时都不会自行开始。
每次运行以当前姿态和位置为起点；场地不足时人工复位后只测一轮即可。

菜单X进入参数测试，`HIGH_SPEED_CORNER_TEST=true`为三项高速运动测试，false为H1～H4直行整定。
完整入口与按钮规则见 [启动模式](STARTUP_MODES.md)。

## 比赛运行

普通非标定构建连接场控即可进入比赛权限；Competition构建同样支持无场控时的A/B/X菜单。
比赛回调与场控共同启用同一个 `autonomous_program`，每个自动时段只运行一次；禁用会立即取消输出。
比赛自动不依赖手柄，A/B 测试入口不在比赛阶段启用，连接场控时关闭调试回传。

任一动作启动失败、反馈故障、超时或被取消，整条路线停止，后续动作不继续执行。
`-route.csv` 的 `result` 为0未开始、1运行、2正常完成、3取消、4故障；具体原因显示在遥控器上。


## 位姿导航与单侧Swing（2.1.0-point1，待实车）

```cpp
RunRoute({
    MoveToPoint(500, 500),                     // 全局X前/Y左，单位mm
    MoveToPoint(500, 1000, 300, 200),           // 可选：直行rpm、转向rpm
    Swing(90, drive::pivot_side::left),         // 左侧制动，右侧前进，逆时针90度
    Swing(-90, drive::pivot_side::right, 200),  // 右侧制动，左侧前进，顺时针90度
});
```

`MoveToPoint` 从当前位姿求目标方位，换算成相对IMU转角，调用原转向控制器；到位零速后同一调度周期重算剩余距离并交给原直行控制器。一个命令包含两个阶段，没有额外Wait或新线程。首版为先转后直，不是曲线路径跟踪；行驶中仍由原直行航向环保持起步方向。坐标原点为启动后首次有效定位的底盘中心，X初始前方、Y初始左方；转向结束不重置坐标。

默认最高速度复用540电机rpm，增益、前馈、角速度/直线速度规划均沿用当前配置。全局终点容差与位姿新鲜度在 `performance-config.h` 的 `PointControl()` 独立配置，默认5mm与200ms。点位动作根据剩余距离分配朝向和沿程误差预算，普通转向0.8°并不等于任意距离下都能满足5mm二维误差；点位会收紧对应容差并降低末端最低补角转速。缺失、失效、非有限或过期位姿报POSE ERROR；原动作完成但坐标仍超差报POINT ERROR，全路线撤输出，不盲目反复冲向目标。坐标有效不等于真实位置无漂移；首版需要实车确认容差及点位精度。

`Swing` 的角度相对当前位置，正角逆时针，指定固定侧；正角+固定右侧时左侧后退，负角+固定左侧时右侧后退。它不是双侧同时前进的圆角。固定侧始终零输出并主动brake，活动侧使用原前馈和速度PID；同一活动侧rpm产生的角速度为原地双侧反转的一半，规划自动按该几何关系换算。brake不是机械锁止，固定侧仍可能被推移，必须实车检查。

默认 `src/route.cpp` 仍为原1500/90/1500，提供上述动作的注释示例，取消注释并替换动作表后由菜单A或比赛自动执行。X原三项测试不增加按键。建议第一次仅运行一条MoveToPoint短距离，再分别测试左右Swing；B/摇杆取消、场控禁用及反馈故障继续由原调度统一撤输出。遥测沿用DRA与DTN/DTP，Point两个阶段同一步号；位姿另看DPO，未新增无线高频输出。
