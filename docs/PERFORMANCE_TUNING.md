# 提速与转向规划实验

当前工作区版本为`2.0.6-route3`，基于已发布`core-v2.0.0`，未发布新标签。上一版turn1已有首轮90°转向实车数据；本轮末端优化、540rpm长直线及其他转角/负载尚待验证。
开关位于`include/performance-config.h`：`EXPERIMENTAL_FAST_ROUTE=true`使用候选，false恢复2.0速度和运动参数。
所有入口、场控交接、机械定位前推以及角度/距离/停稳/故障判定保留。
route3自动直行/原地转向不再增加停稳确认计时，到位及零速门槛满足即交接；X单项和圆角仍250ms，见路线指南。

## 速度单位

用户已确认目标为**轮端450rpm**。现有API和遥测单位仍是电机减速箱输出轴rpm，外部齿轮主动30、从动36，
因此默认直线/单侧目标上限设为**540电机rpm**，换算为450轮端rpm；2.75英寸轮理论线速度约1646mm/s。
轮端500rpm时理论约1829mm/s，是理想几何速度而非带载最低速度。

`DriveStraight(1000)`使用当前默认540电机rpm；`DriveStraight(1000,450)`则是电机450rpm、轮端375rpm。
短路线可能未加到上限就必须减速，不能只按轮速上限推算整段用时。
500mm标准模型峰值约216电机rpm/180轮端rpm，当前3m模型才达到约542电机rpm的瞬时峰值。

## 候选改动

| 参数 | 2.0基线 | 当前实验 |
| --- | --- | --- |
| 直行/圆角单侧默认上限 | 330电机rpm | 540电机rpm（轮端450） |
| 直行加速/减速 | 320/320 rpm/s | 400/400 rpm/s |
| 直行位置比例/最大补位 | 0.25 rpm/mm / 20 rpm | 0.6 rpm/mm / 60 rpm |
| 直行最低补位 | 15 rpm | 18 rpm |
| 原地转向默认上限 | 140电机rpm | 540电机rpm |
| 原地规划跟踪P/D | 原角度P/D：1.6 / 0.2 | 3.0 / 0.10 |
| 原地参考结束后补角P | 沿用角度P | 6.0，仅作用于末端 |
| 原地规划角加速/角减速 | 原目标轮速变化限制 | 900 / 1200 度/秒² |
| 圆角终点位置比例/最低/最高补位 | 0.6 / 12 / 30 | 0.8 / 15 / 40 |

圆角弯内180rpm、入弯偏好130rpm、曲率/轮加速度预测、出弯对齐和240rpm/s出弯加速均保留。
15°过程航向保护、1.5°圆角终点、0.8°原地终点、5mm距离及停稳条件未放宽，超时配置也未延长。
540rpm是单侧上限，不能让弯内中心强行按540rpm前进。
原地转向已升级为角速度梯形规划＋角度纠偏＋轮速闭环，制动预留120ms；
短角度自动成为三角形速度参考，540rpm仍只是上限。参数、数据与单独回退方式见[转向整定](TURN_TUNING.md)。

## 软件对照结果

- 12组3m正反直行/额外阻力/左右响应对照均完成：平均5930→4543ms，标准5360→4380ms，候选终点最大2.745mm。
- 原fast1的18组转向模型为3104→2856ms；turn1同组平均1507ms，当前turn2为1331ms。
- 108组转向负载/轮距/响应模型：turn1→turn2平均1556→1345ms，当前最大终点0.758°；详见转向整定。
- 108组正反30°/90°/120°圆角、轮距、阻力和响应对照均完成：平均5653→5258ms，标准90°为5020→4820ms，终点最大1.135°。

上述为简化模型，不是实车成绩。第一版更激进的圆角补位18/45rpm、位置比例1.0在模型中触发END HEADING，
已撤回到表中候选，没有通过放宽角度窗口使其通过。早期540rpm直行仍用20rpm补位上限时出现TIMEOUT，
已在候选中提高距离收敛能力并通过对照，不延长时间保护来宣称提速。

高速前馈超过原100～200rpm采集区间仍属外推，模型通过不能证明负载、打滑、温升或场地变化下同样可靠。
下载和运行由操作者在VS Code执行，版本显示应为`2.0.6-route3`；模式和按钮与2.0一致。

当前X测试的STR距离已按用户要求改为1500mm，速度上限540电机rpm；上/下选STR、右/左选方向、A开始。
菜单A自动仍执行原500/90°/500圆角路线。1.5m也不保证达到最高轮速，实际峰值需回传确认。
