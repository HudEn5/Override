# 高速运动整定

底层2.0各构建统一显示版本`2.0.0`，高速环境标识为`HS`。
当前工作区为`2.0.6-route3`候选；本页2.0参数留作基线。X三项测试与自动均接入实验副本，当前默认上限540电机rpm，见[提速实验](PERFORMANCE_TUNING.md)。
默认构建启用高速配置，低速参数通过显式Test构建保留；两者使用独立控制器实例。
高速环境提供直行整定和连续圆角测试预设，共用底层控制器。

开机菜单A自动、B手动、X测试。A执行 `src/route.cpp`，X进入本页参数测试，见 [启动模式](STARTUP_MODES.md)。
高速参数共同来源为 `include/performance-config.h`。

## 当前预设：直行接逆时针 90° 再直行

`include/test-config.h` 的 `HIGH_SPEED_CORNER_TEST = true` 时，X测试默认选中 CNR +90°：
前进 500 mm → 连续逆时针圆角 90° → 沿新方向前进 500 mm，最后停稳。
直线距离指圆角切点前后长度，另有圆角路径长度；不代表整条路线只有 1000 mm。
保留原圆角控制、250 mm 参考最小曲率半径、325 mm 轮距与控制增益，不使用新 H4 的位置增益。
单侧目标上限为 330 rpm，弯内由预测及航向跟随自动降低，短直线也可能达不到上限。

高速预设在 `HighSpeedCornerControl` 中复制普通圆角配置，再覆盖以下规划参数；普通测试参数不变：

| 参数 | 普通配置 | 当前高速候选 |
| --- | --- | --- |
| 直线加速 / 减速 | 180 / 120 rpm/s | 320 / 320 rpm/s |
| 预测左右轮加速 / 减速预算 | 180 / 120 rpm/s | 320 / 320 rpm/s |
| 弯内中心速度上限 | 140 rpm | 180 rpm |
| 入弯偏好速度 | 100 rpm | 130 rpm |
| 弯内加速度 | 60 rpm/s | 120 rpm/s |
| 出弯加速度 | 60 rpm/s | 240 rpm/s |

预测预算是候选值，尚非已测定的转弯机械能力；保留 15% 余量、200 ms 响应预留和全部完成/故障判定。
该候选通过 36 个正负 90°、轮距、负载、左右响应模型组合，标准模型耗时由 6680 降至 5020 ms；
这些是软件模型结果，实际提速和精度仍需实车采集验证。
补充当前高速参数的30°/90°/120°正反向、100/200/330/600rpm上限及负载/轮距/响应组合共432组，全部完成。
模型过程最大航向偏差分别约3.89°/6.33°/6.68°，终点最大误差均小于0.74°；这些不替代不同角度实车验证。

下载运行后等待惯导校准，按X并松开，确认CNR +90；此时A执行单项动作，B取消，拨摇杆接管，Y开关回传。
右键为逆时针，左键可选顺时针对照，上/下循环选择STR/TURN/CNR。保持A不会重复启动，开机不会自行运动。
本预设沿用 2 Hz 精简回传，只发送 DCR、DVL；不发送 DHS，基础采样和诊断 CSV 仅有表头。
DONE 后至少等待 1 秒，确保终态已传回；测试过程中不要因进入减速而提前取消。

将 `HIGH_SPEED_CORNER_TEST` 设为false并重新编译，X测试恢复下述H1～H4整定，A自动不受影响。
普通 Test、Competition 和 Calibration 构建不受该预设影响。下载由操作者在 VS Code 完成。

## 构建与切换

```powershell
.\scripts\build.ps1 -Rebuild -Mode HighSpeed
```

生成 `build/highspeed/Bartmoss.bin`，不覆盖默认的 `build/Bartmoss.bin`。
构建不会自动下载或切换 VEX 扩展默认下载文件，VS Code 任务列表也提供对应构建任务。

若沿用默认编译/下载按钮，在 `include/control-config.h` 将 `BARTMOSS_HIGH_SPEED` 改为 1，
另外两个环境宏保持 0，再默认编译下载。设回 0 并重新默认编译下载即可回到原低速环境。
下载后核对主控上的版本与 HS 标识。高速不能同时启用比赛或标定宏，接入场控时不运行高速测试。

## 档位

参数集中在 `include/test-config.h`。距离为单段行程，正/负方向由手柄选择。

| 档位 | 距离 | 目标峰值 | 约合线速度 | 加速 / 减速 | 位置增益 / 纠偏上限 |
| --- | --- | --- | --- | --- | --- |
| H1 | 1500 mm | 200 rpm | 610 mm/s | 240 / 240 rpm/s | 原配置 |
| H2 | 1500 mm | 265 rpm | 808 mm/s | 320 / 320 rpm/s | 原配置 |
| H3 | 1800 mm | 330 rpm | 1006 mm/s | 320 / 320 rpm/s | 原配置（对照） |
| H4 | 1800 mm | 330 rpm | 1006 mm/s | 320 / 320 rpm/s | 原配置各乘 2（候选） |

H2→H3 主要提高目标速度。2026-11-16 实车复测后保留 H3，H4 改为同速度、同加减速的位置收敛对照，
不再采用之前的 400 rpm/s。当前位置比例增益由 0.25 提至 0.5 rpm/mm，纠偏上限由 20 提至 40 rpm。
该比例纠偏在整段运动生效，并非只在末端生效；在限速和制动约束内帮助补足距离跟踪落后。
最低补位转速仍为 15 rpm，5 mm 位置窗口、5 rpm 停稳速度、250 ms 停稳等待与 200 ms 制动预留均保留。
H3 已有多轮实车数据；新 H4 候选仍待实车验证，不能据此承诺更快。前馈系数来自原有数据，超过 200 rpm 的部分属于外推。
本版不自动修改前馈、速度 PID 或航向增益，也不自动拟合或保存新参数。

## H1～H4 直行操作

1. 从 H1 开始，在地面正常负载下准备好 1.5～1.8 米行程和额外制动空间，等待惯导校准与车辆停稳。
2. 上/下短按选档，最高/最低档不会循环跳转；右键选择前进，左键选择后退。
3. 按一下 A 执行一段，松开不取消；B 取消，摇杆接管。Y 只开关回传。
4. 等 DONE 后观察结果，再重新按 A 重复；建议同一档位、同一方向做 5～10 轮再升档。

运行中换档和换向无效，按住 A 不重复执行。取消、禁用或故障恢复后必须重新按 A。
每轮开始重新锁定当时航向，手臂、夹爪、气动继续使用原有独立手控。

## 指标与回传

接收方法与日常测试一致：

```powershell
node scripts/monitor-drive-websocket.mjs 120
```

先按 Y 开启回传，再按 A 开始。等到完成结果已回传后再关 Y。
高速模式仅以最多 2 Hz 回传 DTP、DHD、DVL 和 DHS / `-tuning.csv`，减少无线链路负担。
内部控制和指标计算频率不变。两侧实际反馈转速可由 `-velocity.csv` 的目标减误差获得；
高速模式不发送 DS2、DLM、DSQ，因此基础速度、电机诊断、质量 CSV 只有表头。
日常测试和标定模式仍保留原有完整回传。接收脚本检查字段数、有限数值及标志/枚举范围，
可拒绝明显错位记录，但这些检查不能保证检测所有传输损坏。DHS 字段如下：

| 字段 | 含义 |
| --- | --- |
| run / stage / direction | 启动编号、档位 1～4、方向 ±1 |
| state | 0 就绪、1 运行、2 完成、3 取消、4 故障 |
| elapsed_ms | 动作耗时，包含末端停稳 |
| distance_mm / remaining_mm | 编码器估计距离与终点剩余距离 |
| peak_rpm | 顺运动方向的实际中心速度峰值 |
| peak_heading_deg | 相对起步航向的最大偏差 |
| speed_rms_rpm | 左右侧速度误差合并的时间加权 RMS，按新速度样本累计 |
| high_voltage_ms | 任一侧指令电压绝对值达到 11.5 V 的累计时间，并非实测电压饱和时间 |
| at_speed_ms | 实际中心速度 ≥ 目标 90%，且规划参考速度 ≥ 目标 95% 的最长连续时间 |
| qualified | 正常完成且上述连续达速时间 ≥ 300 ms，表示速度项达标 |

`qualified` 不是整定整体通过结论；还需检查航向、外部测量的终点、重复性和高电压持续时间。
不足 300 ms 的瞬时峰值不算达速，取消和故障不算合格。末端统计在该轮结束后冻结，下一轮重新累计。
回传是最多 2 Hz 的快照；换档或启动新轮会替换当前快照，因此 DONE 后至少等待 1 秒再操作下一轮。

遥控器显示 H 档位、方向、状态、实际峰值 P 和航向峰值 E。
结束后 SPEED OK 表示速度项达标，LOW SPEED 表示虽然完成但未满足连续达速条件。
高速环境只在内容变化时更新遥控器，并将显示循环间隔设为 500 ms；控制周期仍为 10 ms。

## 保留的低速基线与验证范围

原 `test-config.h`、直行/转向/圆角控制算法、硬件接线、前馈系数和速度 PID 均保持原样。
H4 的位置配置只在高速控制器的局部副本覆盖，H1～H3 和低速配置不变。
共享互斥锁继续保护整包状态，高速控制器只由主循环调用，最终电机写入点不变。

本版本通过四档正反方向模型、完成与达速判定、启动按键防误触、取消/接管/禁用/反馈故障检查，
并验证高速状态快照的并发一致性及 DHS 分片协议。模型通过不能替代实车调参。
