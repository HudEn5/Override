# 高速测试与性能参数

当前开发版2.1.0-point1，参数以performance-config.h为准；历史阶段说明见[整定历史](history/TUNING_LEGACY.md)，原地转向细节与数据见[转向整定](TURN_TUNING.md)。

## 参数入口与单位

| 入口 | 用途 |
| --- | --- |
| include/control-config.h | 硬件、几何、前馈、速度PID和普通控制器参数 |
| include/performance-config.h | 共用运动预设、实验提速开关、正式自动参数 |
| include/test-config.h | X三项、H1～H4与标定档位 |

API与遥测的rpm为电机减速箱输出轴转速，30:36外部减速使540电机rpm对应450轮端rpm。2.75英寸轮理论线速度约1646mm/s；实际速度受行程、负载、加减速、打滑和电池影响。

| 当前参数 | 数值 |
| --- | --- |
| 直行/原地/圆角单侧目标上限 | 540电机rpm |
| 自动直行加速/减速 | 400/400 rpm/s |
| 直行位置P/最大纠偏/最低补位 | 0.6 rpm/mm / 60rpm / 18rpm |
| 原地角加速/角减速 | 1200/1000度/秒² |
| 转向预留/角速度滤波 | 100/20ms |
| 转向跟踪P/D、末端P | 3/0.10、6 |
| 转向最低转速/末端最低转速 | 60/30rpm |
| 圆角中心/入弯偏好 | 180/130rpm，另受预测限速约束 |
| 自动直行/原地确认 | 0ms，精度与零速门槛仍需满足 |
| X单项及圆角确认 | 250ms |

EXPERIMENTAL_FAST_ROUTE=false恢复2.0预设；TURN_ANGULAR_PROFILE=false切回角度PD；TURN_FAST_FINISH只切换末端参数，不恢复整套turn2规划。540rpm是上限，短段不一定能达到；不能强制弯内中心速度等于单侧上限。

## 日常测试

启动校准完成后菜单X进入测试，上/下选STR/TURN/CNR，左/右选方向，A启动、B取消、Y切换LOG。STR为1500mm，TURN为90°，CNR为500/90°/500；菜单A执行src/route.cpp，当前为1500→原地90°→1500，二者不要混淆。MoveToPoint/Swing示例和参数见[路线指南](ROUTE_GUIDE.md)。

## H1～H4整定

将HIGH_SPEED_CORNER_TEST设为false进入四档直行整定，每次A只运行一轮。H1～H4为200/265/330/330rpm，距离1500/1500/1800/1800mm；H3保留基线，H4在同速同加减速下将位置P与纠偏上限乘二。它们不等同于当前540rpm正式路线。

qualified表示正常结束且实际中心速度达到目标90%、参考速度达到目标95%的连续时间至少300ms，不代表整体整定验收。还要核对航向、外部终点、重复性和高电压持续时间；瞬时峰值不算达速。终态冻结，DONE后至少等1秒方便2Hz采到。

## 数据与验证边界

内部采样约50Hz，高速最多2Hz按需回传，默认LOG:OFF。DTP/DTN/DTA/DVL/DCR/DRA/DPO记录动作与位姿；H档另有DHS。速度可由velocity.csv的目标减误差获得，基础速度/电机诊断CSV仅有表头是高速精简模式的预期行为。字段定义以接收脚本表头为准。

H档统计包括距离、余距、峰值轮速、航向峰值、速度误差RMS、高电压累计时间、连续达速时间与qualified；11.5V指令阈值不等于实测饱和。采样低频可能漏过瞬时峰值，不能用目标/电压零值代替实际零速。

当前34个宿主机程序和五种SDK构建已通过；turn3、MoveToPoint与Swing待实车。前馈在100～200rpm采集区间外仍属外推，不保证跨场地、温升和负载一致。保留的低速Test与独立Calibration用于回归与重新标定，不因目录整理移除。
