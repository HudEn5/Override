# 启动与模式选择

普通运行版本使用与 Tungsten 相同的 A 自动、B 手动，另外加入 X 测试。默认、高速、Test、Competition
构建都支持此菜单；Calibration 仍保留独立标定入口。

## 无场控运行

初始化校准期间显示INITIALIZING并保持所有电机停止；结束后显示 `A:AUTO B:MANUAL`、`X:TEST`。
开机已经按住的按钮需要先松开再选择。
每次选择后松开 A/B/X、摇杆回中，才进入所选模式。可先在菜单按 Y 打开回传，再选择自动，记录完整起步。

| 选择 | 行为 |
| --- | --- |
| A 自动 | 惯导就绪且车停稳时可选择；松开选择键后执行一次`src/route.cpp`，结束停车等3秒再回手动 |
| B 手动 | 原摇杆、手臂、夹爪、气动控制 |
| X 测试 | 进入运动测试，上/下选项目，左/右选方向，A开始、B取消 |

自动中按 B 取消并回手动，拨动摇杆可立即接回手动驾驶；取消后按住 A 不会再次启动。
自动完成后的3秒倒计时保持停车，B或摇杆仍可接管；场控自动不执行这段本地转手动倒计时。
手动或测试中，停车后长按 B 一秒返回菜单；测试里 B 先取消动作，再继续长按才返回菜单。
手柄断开会停止本地动作并回菜单，重连不会自动恢复。

X 只有在菜单中用于选择测试；进入手动/测试后仍是原气动按钮。选择用的 X 会被消耗，不能误切气动。
自动运行时手动机构按键不接管自动输出；当前路线接口主要控制底盘，机构仍保持停止/保持状态。

## X 测试项目

默认高速构建中 `HIGH_SPEED_CORNER_TEST=true`：提供 STR/ TURN/ CNR 三项，默认 CNR。
直行默认500 mm、330 rpm，原地转向90°、140 rpm，圆角500/90°/500、330 rpm单侧上限；
使用高速直行与圆角配置，上限不等于实际必达速度。

设 `HIGH_SPEED_CORNER_TEST=false` 并重新编译，X进入原H1～H4直行整定。A自动和B手动不受此参数影响。
普通非高速Test/Competition构建中，X使用 `test-config.h` 的原低速三项参数；自动仍共用高速路线参数。

## 场控优先

连接比赛开关或场控后，菜单和本地选择失效，统一按场控使能及比赛回调分配自动/手动。
默认、高速、Test、Competition构建均可执行同一条正式自动路线，无需因菜单选择重编译。
禁用立即停车；比赛自动不依赖手柄在线。调试回传在场控连接期间关闭。

本地自动与场控自动切换时取消原运行，建立新运行周期，不能接着执行上一来源的半条路线。
拔掉场控后回菜单，不自动恢复原模式。独立Calibration构建保持原有权限，不用于正式自动。

模式状态只由主循环修改；显示和回传继续读取带mutex的整包快照，没有新增线程或额外电机写入点。

与Tungsten的源码对照、明确保留的差异及验证边界见 [入口核对记录](STARTUP_AUDIT.md)。
