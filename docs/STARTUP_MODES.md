# 启动与模式选择

普通运行版本使用与 Tungsten 相同的 A 自动、B 手动，另外加入 X 测试。默认、高速、Test、Competition
构建都支持此菜单；Calibration 仍保留独立标定入口。

## 无场控运行

初始化校准期间显示INITIALIZING并保持所有电机停止；结束后显示 `A:AUTO B:MANUAL`、`X:TEST`。
开机已经按住的按钮需要先松开再选择。
每次选择后松开 A/B/X、摇杆回中，才进入所选模式。可先在菜单按 Y 打开回传，再选择自动，记录完整起步。

| 选择 | 行为 |
| --- | --- |
| A 自动 | 八台底盘电机、惯导、位置/速度反馈及位姿均有效且车停稳时可选择；松开选择键后执行一次`src/route.cpp`，结束停车等3秒再回手动 |
| B 手动 | 原摇杆、手臂、夹爪、气动控制 |
| X 测试 | 进入运动测试，上/下选项目，左/右选方向，A开始、B取消 |

自动中按 B 取消并回手动，拨动摇杆可立即接回手动驾驶；取消后按住 A 不会再次启动。
自动完成后的3秒倒计时保持停车，B或摇杆仍可接管；场控自动不执行这段本地转手动倒计时。
当前自动选择路线7：MoveToPoint(300,300,400,300,10000)，在src/route.cpp改TEST_ROUTE选择其他路线；X的A键仍启动单项测试。
route3自动直行/原地转向到位且零速门槛满足即交接，额外确认计时为0；X单项仍250ms，完成后的3秒回手动流程保持原样。
手动或测试中，停车后长按 B 一秒返回菜单；测试里 B 先取消动作，再继续长按才返回菜单。
手柄断开会停止本地动作并回菜单，重连不会自动恢复。

菜单未就绪时显示具体原因：MOTOR OFF、IMU WAIT、POSITION ERR、SPEED ERR、MOVING或POSE WAIT。位姿丢失锁存显示POSE RESET:RESTART；把车放回已知起点再重启程序，不会因电机重新上线而自动清除失效坐标。本地A自动统一要求位姿有效；X距离/转向分项不依赖全局位姿，仍检查各自硬件反馈。测试起步先检查反馈，再判断MOVING，掉线不会冒充车辆运动。

X 只有在菜单中用于选择测试；进入手动/测试后仍是原气动按钮。选择用的 X 会被消耗，不能误切气动。
自动运行时手动机构按键不接管自动输出；当前路线接口主要控制底盘，机构仍保持停止/保持状态。

## X 测试项目

默认高速构建中 `HIGH_SPEED_CORNER_TEST=true`：提供 STR/ TURN/ CNR 三项，默认 CNR。
当前高速X测试直行默认1500 mm、540电机rpm，原地转向90°、540电机rpm，圆角500/90°/500、540电机rpm单侧上限；
关闭`performance-config.h`中的实验开关后恢复2.0的330/140/330rpm，详见[提速实验](HIGH_SPEED_TUNING.md)。
使用高速直行与圆角配置，上限不等于实际必达速度。

设 `HIGH_SPEED_CORNER_TEST=false` 并重新编译，X进入原H1～H4直行整定。A自动和B手动不受此参数影响。
普通非高速Test/Competition构建中，X使用 `test-config.h` 的原低速三项参数；自动仍共用高速路线参数。

## 场控优先

连接比赛开关或场控后，菜单和本地选择失效，统一按场控使能及比赛回调分配自动/手动。
默认、高速、Test、Competition构建均可执行同一条正式自动路线，无需因菜单选择重编译。
禁用立即停车；比赛自动不依赖手柄在线。调试回传在场控连接期间关闭。

本地自动与场控自动切换时取消原运行，建立新运行周期，不能接着执行上一来源的半条路线。
拔掉场控后回菜单，不自动恢复原模式。独立Calibration构建保持原有权限，不用于正式自动。

模式状态只由主循环修改；显示和回传继续读取带mutex的整包快照，没有新增线程或额外电机写入点。




## Tungsten源码对照

核对对象为工作区参考 Tungsten 的以下源码，不以印象判断：

- `src/elementOS_main.cpp`：`eos::Initialize`、`eos::EosMain`。
- `src/main.cpp`：`autonomous`、`usercontrol`、VEX比赛回调注册。
- `src/route.cpp`：`eos::AutoRoute`。

## 核心行为

| 环节 | Tungsten | Bartmoss |
| --- | --- | --- |
| 初始化 | 先校准惯导，再进入模式选择 | 校准期间禁止选择和运动，显示INITIALIZING；校准结束才接受选择 |
| 无场控选择 | A自动调试、B手动调试 | A自动、B手动，增加X测试 |
| 本地自动 | 执行一次路线 | 执行一次同一份`src/route.cpp` |
| 本地自动结束 | 停车等待3000ms，再转手动 | 同样停车等待3000ms，显示倒计时，再转手动 |
| 场控已连接 | 跳过调试选择，使用比赛回调 | 忽略本地选择，使用场控使能/阶段及比赛回调 |
| 场控自动结束 | 保持比赛阶段，不执行本地3秒转手动 | 保持停车等待场控，不自行转手动 |

复核发现上一版本地自动完成后立即转手动、校准期间可先选择手动，与参考不完全相同；本次已修正。
正常控制周期下3秒计时会量化到周期边界，验证接受3000～3020ms，不声称硬件毫秒级零误差。

## 明确保留的扩展与实现差异

| 项目 | 差异与原因 |
| --- | --- |
| 选择输入 | Tungsten支持A/B和主控触屏按钮；Bartmoss当前使用手柄A/B/X，未复制触屏选择 |
| 持键/同时按键 | Tungsten是按住即选、A优先；Bartmoss要求先松键、单键选择，并在选择后松键和摇杆回中 |
| 主动中断 | B或摇杆可中断本地自动并接回手动；停车长按B一秒返回菜单，这是新增功能 |
| X气动复用 | 只在菜单用X选测试，进入手动/测试后恢复原气动用途，选择用的X不触发机构 |
| 执行模型 | Tungsten使用回调/任务和阻塞路线；Bartmoss以主循环状态机推进，唯一电机写入点不变 |
| 数据保护 | 共享快照和比赛回调使用mutex，模式本身只由主循环访问 |
| 初始化故障 | Bartmoss惯导故障时自动不可选，但可进入手动排查；校准进行中所有运动仍关闭 |
| 测距基准 | Tungsten有独立编码器并初始化归零；Bartmoss没有独立里程计，每个距离动作记录驱动电机当前位置作为起点 |
| 接入/拔出场控 | Bartmoss显式取消原所有者的运行并建立新周期，拔出回菜单，不续跑本地半条路线 |

因此本工程与参考的核心入口流程已对齐，但并非逐行相同，也不将扩展功能说成原工程已有。

## 验证边界

软件检查覆盖启动持键、单键/多键、初始化/重连、X不误切气动、本地自动一次执行、完成后3秒停车、
倒计时期间取消、场控无手柄自动、场控自动结束保持阶段、禁用和所有权交接。
这些检查验证源码逻辑，不能替代真实手柄、主控、固件及比赛开关的联调；本次未下载或实车操作。
