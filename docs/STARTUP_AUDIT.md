# Tungsten 启动入口对照

核对对象为工作区参考 Tungsten 的以下源码，不以印象判断：

- `src/elementOS_main.cpp`：`eos::Initialize`、`eos::EosMain`。
- `src/main.cpp`：`autonomous`、`usercontrol`、VEX比赛回调注册。
- `src/route.cpp`：`eos::AutoRoute`。

## 核心行为

| 环节 | Tungsten | Bartmoss |
| --- | --- | --- |
| 初始化 | 先校准惯导，再进入模式选择 | 校准期间禁止选择和运动，显示INITIALIZING；校准结束才接受选择 |
| 无场控选择 | A自动调试、B手动调试 | A自动、B手动，增加X测试 |
| 本地自动 | 执行一次路线 | 执行一次同一份`src/route.cpp` |
| 本地自动结束 | 停车等待3000ms，再转手动 | 同样停车等待3000ms，显示倒计时，再转手动 |
| 场控已连接 | 跳过调试选择，使用比赛回调 | 忽略本地选择，使用场控使能/阶段及比赛回调 |
| 场控自动结束 | 保持比赛阶段，不执行本地3秒转手动 | 保持停车等待场控，不自行转手动 |

复核发现上一版本地自动完成后立即转手动、校准期间可先选择手动，与参考不完全相同；本次已修正。
正常控制周期下3秒计时会量化到周期边界，验证接受3000～3020ms，不声称硬件毫秒级零误差。

## 明确保留的扩展与实现差异

| 项目 | 差异与原因 |
| --- | --- |
| 选择输入 | Tungsten支持A/B和主控触屏按钮；Bartmoss当前使用手柄A/B/X，未复制触屏选择 |
| 持键/同时按键 | Tungsten是按住即选、A优先；Bartmoss要求先松键、单键选择，并在选择后松键和摇杆回中 |
| 主动中断 | B或摇杆可中断本地自动并接回手动；停车长按B一秒返回菜单，这是新增功能 |
| X气动复用 | 只在菜单用X选测试，进入手动/测试后恢复原气动用途，选择用的X不触发机构 |
| 执行模型 | Tungsten使用回调/任务和阻塞路线；Bartmoss以主循环状态机推进，唯一电机写入点不变 |
| 数据保护 | 共享快照和比赛回调使用mutex，模式本身只由主循环访问 |
| 初始化故障 | Bartmoss惯导故障时自动不可选，但可进入手动排查；校准进行中所有运动仍关闭 |
| 测距基准 | Tungsten有独立编码器并初始化归零；Bartmoss没有独立里程计，每个距离动作记录驱动电机当前位置作为起点 |
| 接入/拔出场控 | Bartmoss显式取消原所有者的运行并建立新周期，拔出回菜单，不续跑本地半条路线 |

因此本工程与参考的核心入口流程已对齐，但并非逐行相同，也不将扩展功能说成原工程已有。

## 验证边界

软件检查覆盖启动持键、单键/多键、初始化/重连、X不误切气动、本地自动一次执行、完成后3秒停车、
倒计时期间取消、场控无手柄自动、场控自动结束保持阶段、禁用和所有权交接。
这些检查验证源码逻辑，不能替代真实手柄、主控、固件及比赛开关的联调；本次未下载或实车操作。
